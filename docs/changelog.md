# 更新日志

各版本的下载见 [下载页](https://github.com/SingleJohn/emby-gateway-bin/releases)。升级前请先阅读 [部署与升级](/guide/deployment#升级与回滚) 并备份数据库。

## 下一版本（未发布）

### 新功能

- **管理界面改版**：菜单按任务重新分为六组（首页、监控、安全、接入与路由、媒体库工具、系统），视觉统一为浅色卡片风格，亮色和暗色都重新调整过。见 [管理界面基础](/guide/management-ui)。
- **需要关注**：顶栏铃铛和控制台集中显示待处理的事，包括授权即将到期、Emby 上游不可达、配置异常、有用户正被封禁、有登录被锁定、告警投递失败、STRM 任务失败，点击直接跳到处理页面。
- **防护记录**：拦截事件、登录锁定、当前封禁、告警记录、封禁历史集中在一个页面，可以按条件筛选。见 [防护记录](/guide/security-records)。
- **登录锁定解锁**：可以查看哪些账号或 IP 因登录失败被锁定，并手动解锁。
- **告警记录**：每次告警触发都会留下记录，包括告警内容、发往哪些渠道、哪些失败以及失败原因。见 [告警规则与告警记录](/guide/security-alerts)。
- **路由匹配测试与映射测试**：在 Emby 源页面输入一个媒体路径，就能看到会命中哪条规则、走哪个资源池；路径映射页可以直接测试转换结果。不需要先保存。
- **存储后端新建向导**：先选类型（附带每种类型的适用说明），再填写配置。
- **配置保存更安全**：每个页面只保存自己负责的那部分配置；别人同时修改了同一部分时会提示冲突，由你决定加载最新还是覆盖；有未保存的修改时离开页面会提醒；保存前可以查看改动明细；支持 <kbd>Ctrl</kbd> + <kbd>S</kbd> 保存。
- **配置检查**：新增「被遮蔽的路由规则」提示：一条匹配全部路径的规则排在前面时，它后面的规则永远不会生效。
- **CDN 后端支持 123 回源鉴权**。
- **123 网盘热门视频按需转码**：按播放热度自动转码，带容量保护；支持首播预热、跟随原片分辨率和单档转码。新增「123 转码」页面管理转码文件和任务。见 [123 转码](/guide/pan123-transcode)。
- **123 网盘连接与直链测试**，拼接直链模式支持指定 Root Folder，直链空间管理与错误提示更清楚。
- **系统日志组合筛选**：按级别、模块、Emby 源、后端和关键词组合查找运行日志。

### 改进

- 「网关配置」和「缓存管理」合并为「系统设置」；资源池单独成页。
- 流量分析的「概览」「请求日志」「302 链路」Tab 移到页面顶部，当前 Tab 会写进网址。
- 访问来源的 Top IP 可以一键查看它的请求日志或拦截记录。
- 实时播放、用户与媒体页面重新设计。
- STRM 任务改为卡片展示，每个任务直接显示上次运行的扫描、写入、删除、错误数量。
- 通知渠道页：通知总开关移到页面顶部，每个渠道显示近 7 天的送达和失败次数。
- 授权页突出显示剩余天数，快到期时变色提醒。
- 对象浏览会记住上次使用的后端，当前目录写进网址，刷新后不丢。
- 列表页的筛选条件写进网址，可以把链接直接发给别人。

### 修复

- 改进播放格式协商，减少部分客户端起播失败。
- 恢复相对播放地址，修复 Yamby 无法播放。
- 完善 123 网盘的调用诊断信息，日志中隐藏敏感参数。

## v1.9

发布于 2026-10-16。

### 新功能

- **HTTP Resolver 后端**：对接外部解析服务获取播放地址，可选择直接跳转或由网关中转；兼容 hls2strm。见 [HTTP Resolver](/guide/backend-http-resolver)。
- **匿名播放兼容**：新增开关，兼容不携带任何登录凭据的播放器内核发起的播放请求。

### 改进

- 媒体请求的限流与其他请求分开计算，正常播放不容易被误封。
- 请求防护的配置说明和输入校验更清楚。

### 修复

- HTTP Resolver 中转时转发原始访问前缀，兼容按跳转前地址解析的播放器。
- 完善 HTTP Resolver 中转的兼容性和传输诊断，流量统计更准确。

## v1.8.13

发布于 2026-09-26。

### 新功能

- **用户多 IP 临时封禁**：同一账号短时间内从过多 IP 访问时自动临时封禁，可设置例外用户。
- **封禁历史**：自动封禁留下处罚记录，可按状态和原因筛选。
- **按请求类型限流**：限流按请求类型分别设置和统计。
- **限制 Infuse 重复拉流**：Infuse 已完整拉取过一次文件后，限制它反复整文件重拉。
- **阿里云 CDN 单请求限速**：签名地址可以附带限速参数。

### 修复

- 修复原版 Emby 不支持部分用户接口，导致播放请求返回 503 的问题。
