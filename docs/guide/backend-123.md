# 123 网盘

这页讲怎么用 123 云盘开放平台接入存储后端（类型 `pan123`，界面上叫「123 网盘 Open」）。播放时网关拿到 123 的直链，302 给播放器，视频流量不经过网关。

## 准备工作

在 123 云盘那边准备好：

1. 开放平台的 **Client ID** 和 **Client Secret**（开发者权益需要有效）。
2. 在 123 网页端开通「直链」，网关返回的就是直链空间里的地址。
3. 如果在 123 网页端「直链」→「URL 鉴权」里开启了鉴权，记下**鉴权密钥**和账号 **UID**。

## 基本配置

在 <span class="ui-path">接入与路由 › 存储后端</span> 新建后端，类型选「123 网盘 Open」。

| 界面字段 | 配置字段 | 默认值 | 说明 |
|---|---|---|---|
| Client ID | `client_id` | — | 开放平台 Client ID |
| Client Secret | `client_secret` | — | 开放平台 Client Secret |
| Root Folder ID | `root_folder_id` | `0` | 媒体所在的根目录 ID，`0` 表示网盘根目录。路径映射得到的对象路径都相对于这个目录 |
| 直链模式 | `direct_link_mode` | `api` | 「API 获取直链」或「拼接直链 (UID + objectKey)」，见下一节 |

## 两种直链模式

| | API 获取直链（`api`） | 拼接直链（`compose`） |
|---|---|---|
| 怎么得到直链 | 先按路径查到文件 ID，再调用 123 接口获取直链 | 按规则直接拼出直链地址，不调用直链接口 |
| 123 API 调用 | 每次起播都要调用（有缓存时可省去查文件 ID） | 少，只在需要时查询根目录路径 |
| 起播速度 | 取决于 123 接口响应 | 更快 |
| 适合 | 先跑通、文件不多 | 播放量大、想减少 API 调用和限流 |

### 拼接直链的地址规则

选择「拼接直链」后会多出两个字段：

| 界面字段 | 配置字段 | 说明 |
|---|---|---|
| 自定义域名（含协议，可选） | `compose_base_url` | 在 123 直链空间绑定的自定义域名，例如 `http://downxxxxx.com` |
| 隐藏 UID | `compose_hide_uid` | 123 侧开启了「隐藏 UID」时打开。必须先填自定义域名 |

拼出来的地址分三种情况：

| 情况 | 直链格式 |
|---|---|
| 没填自定义域名 | `https://<UID>.v.123pan.cn/<UID>/<路径>` |
| 填了自定义域名、未隐藏 UID | `<自定义域名>/<UID>/<路径>` |
| 填了自定义域名、隐藏 UID | `<自定义域名>/<路径>` |

这里的 `<路径>` 是从网盘根目录算起的完整路径。「Root Folder ID」不是 `0` 时，网关会自动在前面补上这个目录的路径。

::: warning
拼接直链需要填写 URL 鉴权里的「UID」，否则会报「拼接直链需要填写 UID」。「隐藏 UID」要和 123 侧的设置保持一致，不一致时直链会返回错误码 `1021`。
:::

## URL 鉴权

123 侧开启了直链鉴权，网关这里也要开启，否则直链会返回错误码 `1026`。

| 界面字段 | 配置字段 | 默认值 | 说明 |
|---|---|---|---|
| 启用 URL 鉴权 | `sign_enabled` | 关闭 | 给直链加上鉴权签名 |
| UID | `uid` | — | 123 账号 UID |
| 签名有效期 (分钟) | `valid_duration_minutes` | `30` | 签名多久后失效 |
| Private Key | `private_key` | — | 123 网页端「直链」→「URL 鉴权」里的鉴权密钥 |

开启后「UID」和「Private Key」都必须填写，缺一个起播就会失败。

## 缓存设置

| 界面字段 | 配置字段 | 默认值 | 说明 |
|---|---|---|---|
| 302 缓存有效期 (秒) | `link_ttl_seconds` | `1800` | 网关给生成的直链标注的有效期，对象浏览里复制链接时显示的过期时间按它计算 |
| 映射缓存 | `cache_enabled` | — | 缓存对象路径到 123 文件 ID 的对应关系，API 模式下可以少查一次文件 |
| objectKey→fileID 映射缓存时间 (秒) | `cache_ttl_seconds` | `10800` | 映射缓存的保留时间 |

每次起播网关都会重新生成直链，不会把旧直链发给播放器。

## 连接与直链测试

后端详情底部的「连接与直链测试」会用**当前填写但尚未保存**的配置跑一遍检查。可以填一个「Object Key」（相对 Root Folder 的路径，例如 `movies/avatar.mkv`），测试会额外为这个文件生成并访问一次直链。

检查项包括：

| 检查项 | 看什么 |
|---|---|
| 配置校验 | 字段格式是否正确 |
| URL 鉴权 | 鉴权开关与密钥、UID 是否齐全 |
| access_token | Client ID / Secret 能否换到访问令牌 |
| UID | 填写的 UID 是否与账号一致 |
| 直链流量 | 直链剩余流量是否为 0 |
| 隐藏 UID | 网关的设置是否与 123 侧一致 |
| HTTPS 证书 | 自定义域名用 `https://` 时，123 侧是否上传了证书 |
| Root Folder | 根目录能否访问，对应的网盘路径是什么 |
| 生成直链 / 直链协议 / 访问直链 | 能否生成直链、是否为 HTTPS、直链能否访问 |

每项结果为「通过」「注意」或「失败」，失败项会给出原因和修改建议。

::: tip Emby Web 播放
如果 123 返回的是 `http://` 直链，在 HTTPS 的 Emby Web 页面里播放会被浏览器拦截。可以给自定义域名配置证书，或者改用拼接直链模式。
:::

## 搭配阿里云 CDN

想让 123 的文件通过自己的 CDN 域名分发，可以新建一个「阿里云 CDN」后端，以 123 直链空间为回源地址，鉴权模式选「123 回源鉴权」。具体配置见 [S3 与阿里云 CDN](/guide/backend-s3-cdn)。

## 视频转码

123 网盘后端的详情里有「视频转码（按需导入独立空间）」分区。开启后，网关会把播放次数达到条件的视频导入 123 的独立转码空间，转码完成后按设置分发转码后的版本。可以按目录、文件大小和时长筛选参与转码的视频，设置目标分辨率，并启用本地容量保护，避免转码空间被占满。

转码的完整说明和运维页面见 [123 转码](/guide/pan123-transcode)。

## 常见问题

**access_token 获取失败**
检查 Client ID / Secret 是否正确，开放平台的开发者权益是否仍然有效。

**直链返回 1026**
123 侧开启了 URL 鉴权，网关这边没有开启，或者密钥、UID 填错了。

**直链返回 1021**
「隐藏 UID」与 123 侧设置不一致。

**播放报「Root Folder」相关错误**
「Root Folder ID」不存在或没有权限，在测试里看「Root Folder」一项给出的网盘路径是否符合预期。
