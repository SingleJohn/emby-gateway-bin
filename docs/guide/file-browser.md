# 对象浏览

对象浏览可以像文件管理器一样查看存储后端里的目录和文件，不用另开网盘客户端或对象存储控制台。常见用途：

- 配置 [路径映射](/guide/path-mapping) 或 [STRM 任务](/guide/strm-guide) 前，确认存储里真实的目录结构和文件路径；
- 生成某个文件的直链，用浏览器或播放器直接试播，判断问题出在存储还是网关；
- 123 网盘：查看和开关目录的直链空间。

## 能浏览哪些后端

| 后端类型 | 可浏览 |
| --- | --- |
| S3（`s3`） | 是 |
| 本地目录（`local`） | 是 |
| Local Agent（`local_agent`） | 是 |
| 123 网盘（`pan123`） | 是，额外显示直链空间状态 |
| 115 网盘（`115_open`、`115_cookie`、`115_sub`） | 是 |

阿里云 CDN、Google Drive、HTTP Resolver 不出现在后端列表里。

## 选择后端与目录

- **后端**：在工具栏最左侧的下拉框里选择。进入页面时会自动选中：网址里指定的后端 → 你上次浏览的后端 → 列表中的第一个。
- **进入目录**：点击目录行。工具栏的面包屑显示当前位置，点击任意一级可以跳回去；左侧的向上箭头返回上一级。
- **跳转到路径**：点工具栏右侧的「…」，输入路径后点「跳转」，适合直接进入很深的目录。
- **刷新**：工具栏右侧的刷新按钮重新读取当前目录。

当前后端和目录会写进浏览器地址栏，例如 `#/filebrowser?backend=s3-main&prefix=movies/`。刷新页面后停在原处，也可以把这个链接发给其他管理员，对方打开就是同一个目录。

::: tip 很大的目录
目录会自动连续加载，最多先加载 5000 条记录。超过时底部会显示「目录较大，当前已加载 N 条」，点「继续加载」读取剩余部分。
:::

## 文件操作

文件列表显示名称、大小、修改时间。

- **复制直链**：点文件行右侧的链接按钮，网关为该文件生成一条直链并复制到剪贴板。
- **文件详情**：点击文件行打开右侧抽屉，显示文件名、完整路径、大小、修改时间和 ETag。
  - 图片会直接显示预览；
  - 视频可以点「播放」，在新标签页中用直链打开；
  - 「复制直链」复制同一条直链。
- **复制路径**：目录行右侧的复制按钮复制该目录的完整路径，可以直接粘贴到路径映射或 STRM 任务的媒体目录里。

直链按后端自身的规则生成（例如 S3 的签名地址、网盘的下载地址），有有效期，过期后重新生成即可。

## 123 网盘的直链空间

浏览 123 网盘后端时，页面会额外显示目录的直链空间状态。123 没有直接查询直链空间的接口，状态是网关抽样目录里的文件推断出来的：

| 标签 | 含义 |
| --- | --- |
| 直链空间 | 这个目录就是开启了直链的空间根目录 |
| 直链空间内 | 这个目录在某个已开启的直链空间里（自身或上级已开启） |
| 含直链子目录 | 下级有目录开启了直链，不代表当前目录已开启 |
| 未开启直链 | 抽样文件不在直链空间里 |
| 直链未知 | 无法判断，例如空目录，或超出自动检测范围 |

- 当前目录的状态显示在工具栏的「当前目录：…」标签上；子目录的状态显示在目录名后面，每次最多自动检测前 50 个子目录。
- 管理员可以在目录行右侧开启或关闭直链空间，或用工具栏的「开启当前目录直链」「关闭当前目录直链」。开启后该目录下所有文件都能通过直链访问，并消耗 123 的直链流量；123 侧生效可能有几秒延迟。
- 关闭直链会影响这个空间里的全部文件。目录的状态是「直链空间内」且由上级继承而来时，要到实际开启空间的那一级目录去关闭。

只读账号看不到开关按钮。123 后端的其他设置见 [123 网盘](/guide/backend-123)。
