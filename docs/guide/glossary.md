# 术语速查

| 术语 | 简单解释 |
|---|---|
| Source | 客户端进入网关的 Emby 请求入口，每个 Source 有独立监听端口 |
| 上游 Emby | Source 代理和查询用户/媒体信息的 Emby 服务 |
| 真实媒体路径 | Emby 返回的媒体文件系统路径，也是路由匹配输入 |
| object key | 路径映射后交给存储后端查找文件的相对路径 |
| 路由规则 | 决定某个真实路径使用哪个映射集和资源池 |
| 路径映射 | 把 Emby 路径转换为后端 object key |
| 资源池 | 一个主后端和一个可选备后端的固定组合 |
| 302 直链 | 网关只返回跳转地址，客户端随后直接访问存储 |
| Proxy | 请求或媒体内容由网关代理到上游 Emby |
| Relay | 115 等后端的内容由网关中转，不是 302 |
| 播放会话 | 网关识别到的当前活跃用户播放记录 |
| 观察员 | 可查看脱敏配置和观测数据、不能保存修改的后台身份 |
| 后端独立密码 | 已登录用户用于会话级解锁单个后端配置的密码 |
| Worker 模式 | Google Drive 请求交给外部 Worker 处理 |
| STRM 任务 | 扫描存储并生成本地 `.strm` 与可选元数据文件的任务 |
| `daily_stats` | 从请求日志聚合出的按天统计，清理明细时默认保留 |
