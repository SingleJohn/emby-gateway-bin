# 授权

网关的核心功能需要有效授权才能使用。本页说明怎样激活，授权页上各项信息的含义，以及授权失效后会发生什么。

位置：<span class="ui-path">系统 › 授权</span>

<Shot name="license" alt="授权页：剩余天数、续租信息与已授权功能" />

## 激活

1. 打开 <span class="ui-path">系统 › 授权</span>。
2. 如果顶部状态是「未配置」，先展开下方的「授权服务配置」，按授权提供方给你的信息填写「License Server URL」等项，点「保存配置」。「License Public Key」一般留空，网关会使用内置的公钥。
3. 在「激活授权」卡片的「授权码」输入框中填入授权码，点「激活」。
4. 激活成功后，顶部会显示「有效」和剩余天数，「已授权功能」里会列出可用的功能。

::: tip 网关需要能访问授权服务
激活和之后的自动续租都要连接授权服务。请确认网关所在的机器能访问 License Server URL，包括 DNS、防火墙和代理设置。
:::

授权服务配置也可以在启动时通过命令行参数或环境变量指定，见 [启动参数与环境变量](/reference/cli-env)。用启动参数指定的项会覆盖界面上的设置，「授权服务配置」的摘要里会显示「有 N 项被命令行/环境变量覆盖」。

## 授权页上的信息

### 状态总览

页面顶部的大字会显示「剩余 N 天」，下面的进度条表示离到期还有多远，颜色按剩余时间变化：

| 颜色 | 含义 |
|---|---|
| 绿色 | 授权有效，剩余超过 30 天 |
| 黄色 | 剩余 30 天以内，或者处于宽限期 |
| 红色 | 剩余 7 天以内，或者授权已经不可用 |

旁边有两枚标签：授权状态，以及「播放可用」或「播放已禁用」。下面一行写着到期时间、自动续租的周期和续租失败后的宽限时长。

授权状态有这几种：

| 状态 | 含义 | 播放是否可用 |
|---|---|---|
| 有效 | 一切正常 | 可用 |
| 宽限期 | 已过到期时间（通常是续租没有成功），但还在宽限时长内 | 可用 |
| 未激活 | 还没有输入授权码激活 | 不可用 |
| 已过期 | 授权到期且宽限期已过 | 不可用 |
| 时间异常 | 服务器系统时间不正确 | 不可用 |
| 无效授权 | 授权文件校验不通过 | 不可用 |
| 未配置 | 没有填写授权服务地址 | 不可用 |

### 其他信息

- **最近错误**：最近一次激活或续租失败的原因，以红色显示。排查时先看这里。
- **最近续租 / 最近检查**：显示为「3 分钟前」这样的相对时间，鼠标悬停可以看到具体时刻。
- **License ID / 实例 ID**：联系授权提供方时可能需要提供这两项。
- **已授权功能**：这份授权包含哪些功能，例如 Emby 源管理、核心重定向、安全能力、安全告警、STRM，以及各类存储后端（S3 后端、123 Open 后端、115 Open 后端等）。

右上角的「刷新状态」会立即重新读取授权状态。

## 自动续租与宽限期

激活后不需要手动续期。网关会在后台按授权页上显示的周期自动续租，续租成功后到期时间会顺延。

如果续租失败（例如网络中断、授权服务暂时不可用），网关会持续重试；在宽限时长内功能照常可用，状态显示「宽限期」。**宽限期结束仍没有续租成功，功能就会停用。** 这时关注中心和控制台的「需要关注」都会提醒你；授权剩余不足 14 天时，也会提前提醒。

## 授权失效后会怎样

状态不是「有效」或「宽限期」时，所有需要授权的功能都会停用：

- **播放请求会被拒绝**：播放请求返回 403，提示缺少 `core_redirect`。网关不会把它转交给 Emby 代理，所以客户端会直接播放失败。
- **存储后端不再加载**：未授权类型的后端不会初始化，系统日志的「许可证」模块会出现 `Backend disabled by feature gate`。
- **部分配置不能修改**：修改 Emby 源，或者新增、修改未授权类型的存储后端时，保存会失败，提示 `license feature missing`。

同样的规则也适用于单项功能：比如授权里不包含某种存储后端，即使授权本身有效，这种后端也无法使用。

## 更换机器或重装

网关第一次启动时会生成一个**实例 ID**，并保存在授权目录里（默认是网关工作目录下的 `data/license`，Docker 中是 `/app/data/license`）。授权和实例 ID 是绑定的。

- **升级、重建容器**：只要 `/app/data` 是挂载出来的持久目录，实例 ID 不会变，授权继续有效。
- **数据目录丢失或换了新机器**：会生成新的实例 ID，需要重新激活。迁移时把整个 `data` 目录一起带走，就能保留原来的实例 ID。

需要同时运行多台网关时，请先向授权提供方确认授权方式。

## 常见问题

**激活时报错连不上**：在网关所在机器上测试能否访问 License Server URL；容器部署时注意容器内的 DNS 和代理设置。激活请求的默认超时为 30 秒。

**状态显示「时间异常」**：检查服务器的系统时间和时区，建议开启 NTP 自动校时。时间校正后点「刷新状态」。

**授权有效但某个后端用不了**：看「已授权功能」里有没有这种后端。
