# 防护记录

[防护策略](/guide/security) 里每一次拦截、限流、锁定和封禁，都会在这里留下记录。遇到"某个用户突然播放不了""有人在撞库"或者"告警没收到"时，先来这里看。

入口：<span class="ui-path">安全 › 防护记录</span>

<Shot name="security-records" alt="防护记录页面，顶部是四个统计卡，下方是拦截趋势和事件列表" />

## 页面结构

顶部四个统计卡，点击可以跳到对应的 Tab：

- **拦截与限流**：所选时间范围内被拦截和被限流的请求数。
- **登录失败防护**：被拦下的登录请求次数；有来源正被锁定时，显示锁定数量。
- **当前封禁**：正在被自动封禁的用户数。
- **首要规则**：命中次数最多的规则。

下面是五个 Tab：拦截事件、登录锁定、当前封禁、告警记录、封禁历史。当前 Tab 和筛选条件都会写进网址，可以收藏或发给其他管理员。

## 拦截事件

逐条列出被访问规则拦截、被限流、被登录失败防护拦下的请求。

- **顶部筛选**：Emby 源、请求范围（全部请求 / 普通 API / 媒体请求），以及时间范围。打开「实时追踪」后列表会自动刷新。
- **图表**：「拦截趋势」按天显示访问拦截、限流和其他的数量；「命中最多的规则」列出前几条规则。
- **快捷分类**：全部、访问拦截、限流、登录失败防护，每类后面显示数量。
- **筛选**：规则、客户端 IP、路径前缀、关键词，填好后点「查询」；「重置」清空条件。
- 点击任意一行，查看这次请求的完整信息，包括 IP 归属地。

## 登录锁定

显示 [登录失败防护](/guide/security#登录失败防护) 的实时状态，每 15 秒自动刷新。

- **当前锁定**：已经被锁定的来源 IP、所属 Emby 源、剩余锁定时间和解锁时间。表格上方会写出当前规则，例如"5 分钟内失败 5 次即锁定 1 小时"。
- **即将锁定**：正在累计失败、还没到阈值的来源，显示「失败次数」（如 3 / 5 次）和「计数窗口剩余」。

处理方式：

- 确认是自己人输错密码时，点「解除锁定」，该 IP 可以立即重新登录，失败计数也会清零。只有管理员能操作。
- 点击 IP 地址，跳到「拦截事件」查看这个 IP 的全部登录拦截记录。

::: tip
锁定状态保存在网关内存里，网关重启后会清空。登录失败防护没开启时，这个 Tab 会提示「登录失败防护未开启」并提供「去开启」按钮。
:::

## 当前封禁

列出被 [自动防护](/guide/security#自动防护) 临时封禁、尚未到期的用户：触发范围、Emby 源、用户、触发时的 IP（多 IP 封禁会列出全部 IP 并标出触发的那个）、执行状态、封禁时间、解封时间。

- 执行状态「封禁中」表示正在生效；「已暂停」表示封禁记录还在，但当前策略不再作用于这个 Emby 源（例如关闭了对应策略，或把该源移出了适用范围）。
- 点「解除封禁」会立即解封该用户，并清空他的 IP 统计窗口。
- 用搜索框可以按 Emby 源、用户或 IP 筛选。封禁到期后会自动解除。

## 告警记录

[告警规则](/guide/security-alerts) 每触发一次就记一条：时间、告警规则和类型、告警对象（例如用户或 IP）、Emby 源，以及投递结果。

- **投递结果**：「已送达」表示所有渠道都成功；「部分送达」表示有渠道失败；「投递失败」表示一个都没送出去。成功和失败的渠道会分别列出来。
- **筛选**：按「全部」「已送达」「投递失败」切换，也可以按告警规则或关键词（告警对象、通知内容）查询。
- 展开一行，可以看到通知的标题和正文原文，失败时还会显示每个渠道的错误信息。

近 24 小时内有投递失败时，Tab 标题会显示失败条数，关注中心也会提示。投递失败的同一条告警，10 分钟内只记录一次，网关会继续重试。

## 封禁历史

所有自动封禁的历史，包括已经到期和被手动解除的。可以按状态（未到期、已到期、已解除）、原因（多 IP 超限、持续高频请求）、触发范围、Emby 源筛选，或搜索用户名称、ID、IP。

每条记录显示触发证据（例如当时的 IP 列表或请求频率）、状态、封禁期间记录到的拦截数、封禁和到期时间，以及解除记录。用来回答"这个用户上周为什么被封"。

## 从其他页面进入

- **控制台的「需要关注」和顶栏铃铛**：有用户被封禁、有来源被锁定、告警投递失败或拦截量偏高时，点击条目直接打开对应的 Tab。
- **访问来源**：Top IP 列表里可以一键查看该 IP 的拦截记录。
- **防护策略**：页面右上角「查看防护记录 →」。

## 记录保留多久

拦截事件和告警记录保留 90 天，过期后由网关自动清理。登录锁定只保存在内存中，网关重启即清空。数据库清理的更多说明见 [数据库维护](/ops/database-maintenance)。
