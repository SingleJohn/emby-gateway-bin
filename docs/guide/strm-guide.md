# STRM 任务

STRM 功能扫描可枚举目录的存储后端，在本地生成 `.strm` 文件，并记录每次扫描、写入、跳过、删除和元数据处理结果。

## 支持范围

| 后端 | 目录扫描 |
|---|---|
| S3 | 支持 |
| 本地存储 | 支持 |
| Local Agent | 支持 |
| 123 网盘 | 支持 |
| 115 Open | 支持 |
| 阿里云 CDN | 不支持目录扫描 |
| Google Drive | 当前任务表单不作为扫描源 |
| 115 Cookie / 115 分流聚合 | 当前任务表单不作为扫描源 |

以后端下拉框的实际可选项为准。

## 页面结构

「存储与分发 → STRM 任务」分为：

- **任务配置**：新增、编辑、手动执行、重置重扫和删除任务。
- **最近任务**：查看运行状态、结果统计和逐条事件。

调度器使用单队列执行任务；任务内部可以配置扫描和元数据处理并发数。

## 新建任务

主要字段：

| 字段 | 作用 |
|---|---|
| 名称 | 默认可根据媒体目录自动生成，也可手动修改 |
| 后端 | 用于目录枚举和生成媒体链接 |
| 媒体目录 | 后端内的扫描起点，可通过对象目录选择器选择 |
| 链接目录 | 本地 `.strm` 输出目录，可通过文件系统选择器选择 |
| Base URL | 写入 `.strm` 的 URL 前缀；可留空 |
| 同步间隔 | 自动执行周期，单位秒 |
| 保留媒体目录 | 输出路径包含完整媒体目录层级 |
| 去掉源扩展名 | `movie.mkv` 生成 `movie.strm` |
| 删除失效文件 | 源端消失后删除对应本地文件 |
| STRM 后缀 | 识别为视频的源扩展名集合 |

Base URL 留空时，任务会写入相对媒体路径，例如 `/电影/example.mkv`。只有确认客户端或反向代理能解释该路径时才留空。

## 保留媒体目录

开启后输出目录由“链接目录 + 媒体目录”组成。例如：

```text
媒体目录：media/me3/电影/动画电影/
链接目录：/StrmOne
输出目录：/StrmOne/media/me3/电影/动画电影/
```

适合多个任务共用一个输出根目录，避免不同媒体目录下的同名文件发生冲突。

## 批量创建子目录任务

通过媒体目录选择器可读取当前目录的直接子目录，并为每个子目录创建一个待定任务。保存前统一填写后端、链接目录、同步和元数据参数。

批量创建只处理选择器返回的子目录，不会递归生成无限层级任务。

## 并发与元数据

- **并发线程数**：默认 `8`，最大 `64`。
- **下载元数据**：下载图片、字幕、NFO 等配置后缀文件。
- **覆盖已有文件**：允许覆盖本地已存在元数据。
- **元数据后缀**：指定需要同步的非视频扩展名。

元数据下载会额外消耗上游 API、带宽和本地磁盘 IO。大目录应从较低并发开始观察限流和失败情况。

## 手动执行与重置

- **手动同步**：基于已有状态做一次增量任务。
- **重置重扫**：清除该任务的增量状态并重新扫描。

重置不会自动恢复已经被“删除失效文件”移除的人工文件。输出目录不要混放不受任务管理的同名文件。

## 最近任务与详情

最近任务可按 Profile 和是否运行中筛选。详情包含：

- STRM 写入、跳过、删除和错误
- 元数据写入、跳过、删除和错误
- object key、本地路径、时间和错误原因
- 扫描页数、API 次数和各类计数

排障时先按操作类型过滤，再核对后端、媒体目录和本地路径。
