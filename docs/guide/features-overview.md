# 功能总览

Feiyue Emby Gateway 以播放请求分流为核心，同时提供配置、安全、观测和存储任务能力。

## 播放与路由

| 功能 | 作用 |
|---|---|
| 多 Emby Source | 每个 Source 独立监听并代理一个上游 Emby |
| 路由规则 | 按真实媒体路径前缀或正则选择资源池 |
| 路径映射 | 把 Emby 路径转换为后端 object key |
| 一主一备资源池 | 主后端生成直链失败时尝试备后端 |
| 302 直链 | 让客户端直接访问存储或 CDN，减少网关带宽 |
| Emby 代理回退 | 无法生成直链时继续原始 Emby 播放链路 |

## 存储后端

- S3 兼容对象存储
- 阿里云 CDN Type A 签名
- Google Drive 与 GDrive Worker
- 本地存储和 Local Agent
- 123 网盘 Open，支持 API/拼接直链和自定义域名
- 115 Open、115 Cookie、115 主盘/附盘分流聚合
- 单后端独立密码与会话级解锁

## STRM

- 自动和手动执行的任务配置
- 本地/远端目录选择器
- 按媒体子目录批量创建任务
- 增量扫描、重置重扫和删除失效文件
- 保留源媒体目录结构
- 并发处理和元数据下载
- 最近任务、统计和逐条事件详情

## 安全

- 真实客户端 IP 与可信代理
- IP、User-Agent、路径和方法访问规则
- Allow、Deny 和 Rate Limit 动作
- 下载、同步/离线接口防护
- Emby 登录失败统计与临时封禁
- 播放会话统计、默认并发限额和用户独立限额
- 独立安全事件日志和安全告警

## 观测中心

| 页面 | 关注点 |
|---|---|
| 实时看板 | 当前会话与并发趋势 |
| 流量分析 | 请求、状态、延迟、流量和 302 trace |
| 媒体与用户 | 媒体交付、播放和用户使用统计 |
| 访问来源 | IP 地域、运营商和网络类型 |
| 日志与事件 | 安全拦截和控制台日志 |

控制台还提供今日 KPI、30 天趋势、24 小时分时请求、状态构成和 Source 活跃路数。

## 运维与权限

- PostgreSQL 关系化配置和 revision 激活
- 请求日志月分区、空间预览和管理员手动清理
- 请求日志、聚合统计和安全事件分别设置保留策略
- 管理员与只读观察员登录
- 敏感配置对观察员脱敏
- 多渠道通知、许可证状态、缓存和版本检查

## 典型场景

### 单后端起步

一个 Source、一个后端、一个资源池和一条兜底路由，先跑通真实播放链路。

### 主备容灾

同一 object key 可由两个后端提供时，把它们配置成固定主备。

### 按目录分流

电影、剧集或不同存储根目录使用互斥路由和独立资源池。

### 运营与风控

先开启会话统计和安全事件观测，确认口径后再逐步启用并发限制、登录失败防护和告警。
