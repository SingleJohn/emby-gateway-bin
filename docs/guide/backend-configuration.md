# 后端总览

存储后端是媒体文件实际所在的地方：对象存储、CDN、网盘、本地目录或外部解析服务。网关拿到路径映射后的存储路径，交给后端生成播放器能访问的地址。

这一页讲有哪些类型、怎么选、各类型共有的操作。每种类型的字段在各自的页面里说明。

## 后端在播放链路中的位置

后端本身不会参与播放，必须经过两层引用：

```text
Emby 源的路由规则 ──▶ 资源池（主用 / 备用）──▶ 存储后端
```

后端列表里标着「未使用」的后端，表示还没有任何资源池引用它（"未被任何资源池引用，不会参与播放分发"）。资源池的配置见 [资源池与故障切换](/guide/routing-and-pool)。

## 类型对照

| 类型（配置值） | 界面名称 | 交付方式 | 典型用途 | 文档 |
|---|---|---|---|---|
| `s3` | S3 对象存储 | 预签名直链，302 | AWS S3、MinIO、R2、OSS 等兼容 S3 协议的存储 | [S3 与阿里云 CDN](/guide/backend-s3-cdn) |
| `aliyun_cdn` | 阿里云 CDN | CDN 鉴权直链，302 | 已有阿里云 CDN 加速域名，或给 123 网盘做 CDN 回源 | [S3 与阿里云 CDN](/guide/backend-s3-cdn) |
| `gdrive` | Google Drive | 302 到网关代理地址（流量经过网关）；启用 Worker 后 302 到 Worker | Google Drive 个人盘或共享盘 | [GDrive Worker](/guide/gdrive-worker) |
| `local` | 本地存储 | 302 到网关的签名链接，由网关读取文件并传输 | 媒体就在网关所在的机器上 | [本地存储](/guide/backend-local) |
| `local_agent` | Local Agent 代理 | 302 到另一台机器上 local-agent 的签名链接 | 媒体在另一台机器上，由那台机器直接出流量 | [本地存储](/guide/backend-local) |
| `pan123` | 123 网盘 Open | 302 到 123 直链（API 获取或拼接） | 123 云盘开放平台，可按需转码 | [123 网盘](/guide/backend-123) |
| `115_open` | 115 网盘 Open | 302 或网关中转 | 115 开放平台授权 | [115 网盘](/guide/backend-115) |
| `115_cookie` | 115 网盘 Cookie | 302 或网关中转 | 未开通开放平台的 115 账号 | [115 网盘](/guide/backend-115) |
| `115_sub` | 115 分流聚合 | 302 或网关中转 | 一个主盘加多个附盘轮询，分摊单账号限速 | [115 网盘](/guide/backend-115) |
| `http_resolver` | 外部解析服务 | 302 到解析出的地址；需要中转的片段可选 302 或网关中转 | 交给 hls2strm 等外部服务解析真实播放地址 | [外部解析服务](/guide/backend-http-resolver) |

「交付方式」里写"网关中转"或"流量经过网关"的，视频数据会走网关所在机器的带宽；其余方式视频由播放器直接从存储下载。

## 新建后端

<span class="ui-path">接入与路由 › 存储后端</span>

<Shot name="backends" alt="存储后端页面：左侧按类型分组的后端列表，右侧后端详情" />

1. 点击左侧列表上方的「新建」（还没有后端时是「新建第一个后端」），打开向导。
2. **第 1 / 2 步：选择类型。** 类型按「对象存储与 CDN」「网盘」「本地与自建」三组排列，每张卡片下面有一句说明，点选即进入下一步。
3. **第 2 / 2 步：命名。** 填写「名称」，例如"主力 S3""家里 NAS"。名称只用于界面区分，可以随时修改；ID 会自动生成。选错类型可以点「上一步」。
4. 点「创建并填写配置」。向导关闭后自动选中新后端，在右侧填写连接信息。
5. 填完点击底部「保存」，立即生效。
6. 能做连接测试的类型，保存后做一次测试（见下文）。
7. 到 [资源池](/guide/routing-and-pool) 里把它设为主用或备用后端。

<Shot name="backend-wizard" alt="新建存储后端向导：按分组选择后端类型" />

## 共有字段

所有类型都有以下字段，其余字段按类型不同：

| 界面 | 配置字段 | 说明 |
|---|---|---|
| 详情顶部的名称输入框 | `name` | 界面显示用 |
| 名称下方的 ID | `id` | 自动生成，前缀随类型变化（如 `s3_`、`pan123_`、`open115_`）。资源池通过它引用后端 |
| 右上角开关 | `enabled` | 关闭后这个后端不参与播放，资源池里会显示「已停用」；对象浏览和 STRM 任务也不能再选它 |
| 「类型」 | `type` | 一般在向导里选定 |
| 右上角叉号 | — | 删除这个后端，保存后生效 |

::: warning 不要随手改「类型」
在详情里切换「类型」会清空原来那种类型的全部配置项。误改了可以点底部的「撤销修改」恢复，保存后就找不回来了。
:::

左侧列表支持按名称、ID 或类型搜索。每个后端右侧的标签：「停用」、「N 池」（被几个资源池引用，悬停可看到资源池名称）或「未使用」。

授权里没有包含某种后端类型时，这种类型的后端即使启用也不会生效，详见 [授权](/guide/license)。

## 后端独立密码

可以给单个后端再加一道密码，防止其他能登录管理界面的人随手看到或改动这个后端的凭据。

后端详情最上方是密码面板，状态有三种：

| 状态 | 含义 |
|---|---|
| 「未设置密码」 | 没有独立密码，配置表单直接显示 |
| 「已加密」 | 设置了密码且当前未解锁，配置表单隐藏 |
| 「已解锁」 | 本次已输入过正确密码，可以查看和编辑 |

操作：

- **设置**：点「设置密码」，输入「新密码」后「确认」。设置完成后该后端立即锁定。
- **解锁**：点「解锁」，输入「后端密码」后「确认解锁」。
- **锁定**：解锁后点「锁定」重新隐藏。
- **修改**：点「修改密码」，需要先输入「当前密码」。
- **删除**：点「删除密码」，输入「当前密码」后「确认删除」。

设置、修改、删除密码只有管理员身份能操作。解锁状态只保存在当前页面里，刷新或重新打开管理界面后需要重新解锁。

::: warning 它不是权限隔离
后端独立密码控制的是管理界面是否显示这个后端的配置表单，不会对配置加密，也不影响播放。真正的访问控制靠管理密码和只读账号，见 [系统设置](/guide/system-settings)。
:::

## 连接测试

不同类型的测试入口不同：

| 类型 | 按钮 | 做什么 | 是否需要先保存 |
|---|---|---|---|
| S3 对象存储 | 「连接测试」 | 用已保存的 Endpoint、凭据访问 Bucket，按钮变成「连接成功」或「连接失败」 | 需要 |
| 阿里云 CDN | 「生成签名测试」 | 打开「CDN 签名测试」，输入 Object Key 后「生成」，显示签名后的完整地址和到期时间 | 需要 |
| 123 网盘 Open | 「连接与直链测试」 | 打开「123 网盘连接与直链测试」，逐项检查连接；填写 Object Key 时还会按真实 302 逻辑生成直链并请求 1 字节验证 | 不需要，用当前表单内容 |

115 网盘 Cookie 的「刷新状态」只显示网关里是否已保存 Cookie（「已配置」/「未配置」），不检查 Cookie 是否仍然有效。

其他类型没有单独的测试按钮。最直接的验证办法是：

- 支持对象浏览的类型，到 <span class="ui-path">媒体库工具 › 对象浏览</span> 选中它，看能否列出目录；
- 配好资源池和路由后实际播放一次，到 <span class="ui-path">监控 › 流量分析</span> 的「302 链路」查看这个后端的「尝试」和「成功率」。

## 对象浏览与 STRM 支持哪些类型

| 类型 | 对象浏览 | STRM 任务 |
|---|---|---|
| S3 对象存储 | 支持 | 支持 |
| 本地存储 | 支持 | 支持 |
| Local Agent 代理 | 支持 | 支持 |
| 123 网盘 Open | 支持 | 支持 |
| 115 网盘 Open | 支持 | 支持 |
| 115 网盘 Cookie | 支持 | 不支持 |
| 115 分流聚合 | 支持 | 不支持 |
| 阿里云 CDN | 不支持 | 不支持 |
| Google Drive | 不支持 | 不支持 |
| 外部解析服务 | 不支持 | 不支持 |

只有已启用的后端会出现在选择列表里。阿里云 CDN 没有"目录"的概念，需要扫描文件生成 STRM 时，请为同一份数据另建一个 S3 后端来扫描，详见 [S3 与阿里云 CDN](/guide/backend-s3-cdn#两者组合使用)。相关功能见 [对象浏览](/guide/file-browser) 和 [STRM 任务](/guide/strm-guide)。

## 配置检查清单

- 后端已启用，并且已保存；
- 凭据没有多余空格，且没有过期；
- 路径映射得到的存储路径，在这个后端里确实存在（用对象浏览核对）；
- 资源池引用了这个后端，Emby 源的路由规则引用了这个资源池；
- 播放器所在网络能访问后端最终给出的地址（S3 Endpoint、CDN 域名、本地存储的 Base URL 等）；
- 截图或反馈问题时，遮住 Secret Key、Token、Cookie 等敏感字段。
