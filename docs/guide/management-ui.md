# 管理界面基础

本页介绍管理界面通用的部分：怎么访问和登录、菜单怎么分、配置怎么保存。各页面的具体用法见对应章节。

## 访问地址

```text
http://服务器地址:管理端口/
```

管理端口默认 `18888`；部署时用 `GATEWAY_ADMIN_PORT` 或 `-admin-port` 指定过的，以指定的为准。访问根路径会自动跳到管理界面。

### 控制台路径前缀

在 <span class="ui-path">系统 › 系统设置</span> 的「全局设置」里填写「控制台路径前缀」（对应 `admin.path_prefix`，例如 `asdfg`）后，地址变成：

```text
http://服务器地址:管理端口/asdfg/
```

- 设置后，不带前缀的地址一律返回 404，可以避免管理界面被随意扫到。
- 只能是一段路径：字母、数字、下划线或短横线，不能包含 `/`，最长 64 个字符。
- 保存后立即生效，当前页面需要换成带前缀的新地址访问。请先记下新地址再保存。

## 登录与角色

管理界面有两个密码，都在 <span class="ui-path">系统 › 系统设置</span> 的「全局设置」里设置：

| 字段 | 配置项 | 登录后的身份 | 能做什么 |
|---|---|---|---|
| Admin Password（留空禁用鉴权） | `admin.password` | 管理员 | 查看和修改全部配置，执行解锁、清理、释放会话等操作 |
| Viewer Password（合作方只读） | `admin.viewer_password` | 只读访客 | 只能查看；配置里的密码、Token、API Key、签名密钥会被隐藏 |

登录页只有一个密码框，输入哪个密码就以对应身份登录。

::: danger 没有设置 Admin Password 时不需要登录
`admin.password` 为空时，网关不启用登录认证，任何能访问管理端口的人都能修改配置。部署后第一件事就是设置它。
:::

- Viewer Password 必须在 Admin Password 已设置时才能填写，否则保存会被拒绝。
- 登录有效期 24 小时。网关重启后所有登录都会失效，需要重新登录。
- 登录接口有频率限制，短时间内多次尝试会提示稍后再试。
- 只读访客的修改操作都会被拒绝，只有几项不保存配置、不暴露密钥的检查可以使用，例如 Emby 上游连通性检查、检查更新。
- 「123 转码」页和系统设置里的「数据库维护」只有管理员能看到。

右上角的身份按钮显示「管理员」或「只读访客」，点开有「外观设置」和「退出登录」。

### 后端独立密码

管理员可以给单个存储后端再加一道密码。设置后，这个后端的配置默认锁定，需要在后端详情里点「解锁」并输入密码才能查看和编辑；解锁只在当前页面有效，刷新或退出登录后重新锁定。这个密码不能用来登录管理界面。

- **数字角标**：这个页面有需要处理的事项，例如上游不可达时「Emby 源」显示红色计数。数据来自关注中心。

## 顶栏

顶栏左侧显示当前位置（分组 / 页面），右侧依次是：

- **版本号**：点开可以看到「当前版本」和提交号，点「检查更新」查看是否有新版本，有新版本时可以点「查看 Release」打开下载页。
- **需要关注（铃铛）**：见下一节。
- **亮色 / 暗色切换**。
- **身份按钮**：当前身份、「外观设置」、「退出登录」。

### 关注中心

铃铛汇总各页面里需要处理的事，按严重程度排序，点击条目直接跳到处理的页面：

| 类别 | 例子 |
|---|---|
| 授权 | 尚未激活、处于宽限期、已过期，或 14 天内到期 |
| Emby 上游 | 已启用的 Emby 源上游不可达 |
| 配置 | 端口冲突、路由规则引用缺失或被前面的规则遮蔽等配置异常 |
| 安全 | 有用户正被自动封禁、有来源因登录失败被锁定、近 24 小时有告警投递失败、近 24 小时的拦截次数 |
| STRM | 某个任务最近一次运行失败 |

铃铛上的数字只统计需要动手处理的项（错误和警告），拦截次数、登录锁定这类提示信息不计入。打开管理界面时会拉取一次，之后页面可见时每分钟刷新；也可以在下拉框底部点「刷新」。控制台的「需要关注」和这里是同一份内容。

## 保存配置

配置类页面（Emby 源、路径映射、资源池、存储后端、防护策略、告警规则、通知渠道、系统设置等）的保存方式相同。

### 先改，再一起保存

修改不会立即生效。页面底部的保存栏会显示「N 处修改未保存」，点开是「改动摘要」，逐项列出字段的修改前后值；点「保存」一起提交，点「撤销修改」回到上次加载时的状态。没有修改时显示「已同步到最新配置」。

- 快捷键 <kbd>Ctrl</kbd> + <kbd>S</kbd>（macOS 上 <kbd>⌘</kbd> + <kbd>S</kbd>）等同于点击「保存」。
- 有未保存的修改时切换页面，会弹出「有未保存的修改」，可以选「留在此页」或「放弃修改并离开」；关闭或刷新浏览器标签页时，浏览器也会先确认。
- 保存成功后立即生效，不需要重启网关。例外是「Admin Host」和「Admin Port」，要重启网关后才会按新值监听。

### 每个页面只保存自己负责的部分

每个页面只提交自己负责的那部分配置，其余部分以服务器上的最新配置为准。例如你在「资源池」页保存时，不会覆盖别人刚在「通知渠道」页保存的内容。

### 多人同时修改

如果你打开页面之后，同一部分配置已经在别处（另一个人或另一个浏览器标签页）被保存过，点击保存时会弹出「配置已被其他会话修改」，并说明是哪些部分。可以选择：

- 「加载最新配置」：放弃本页的修改，载入别处保存后的内容；
- 「用我的修改覆盖」：以本页内容为准保存。

拿不准时选「加载最新配置」，确认别人的改动后再重新修改。

::: tip 用脚本修改配置
管理 API 返回配置时会带上版本号响应头 `X-Config-Version`。提交配置时带上这个请求头，网关会在版本不一致时返回 `409`，避免覆盖别人的修改；不带则直接保存。
:::

## 可以分享的链接

不少页面会把当前 Tab、筛选条件写进网址，刷新不丢，复制地址栏的链接发给别人也能打开同样的视图。例如：

- 流量分析当前所在的 Tab（概览、请求日志、302 链路）；
- 防护记录里只看投递失败的告警记录；
- 对象浏览里某个后端的某个目录。

## 外观

点顶栏的亮色 / 暗色按钮可以直接切换。更多选项在身份按钮的「外观设置」里：

| 选项 | 说明 |
|---|---|
| 模式 | 亮色、暗色、跟随系统（默认） |
| 品牌主色 | 预设色或自选颜色 |
| 控件圆角 | 4 到 14 |
| 毛玻璃强度 | 只作用于侧栏、顶栏、首页头部与弹层 |

这些设置只保存在当前浏览器里，不影响其他人。
