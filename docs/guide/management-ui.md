# 管理界面

管理后台默认位于：

```text
http://<服务器IP>:<管理端口>/ui/
```

程序默认管理端口为 `18888`。部署时若设置了 `GATEWAY_ADMIN_PORT`，请使用覆盖后的端口；配置了控制台路径前缀时，还需把前缀放在 `/ui/` 之前。

## 登录与权限

### 管理员

使用 Admin Password 登录，具有配置写入、凭据管理、数据库维护、会话释放等完整权限。

### 观察员

使用 Viewer Password 登录。观察员：

- 可以查看页面和大多数查询结果。
- 配置中的密码、Token、Cookie、API Key 和签名密钥会被清空或脱敏。
- `POST`、`PUT`、`DELETE` 等写操作会被拒绝。
- 仍可使用少量不保存配置且不暴露敏感信息的健康/签名检查接口。

Viewer Password 只有在 Admin Password 已设置时才能启用。

### 后端独立密码

全局管理员可为单个后端设置独立密码。它不能用于后台登录；已经登录的用户在后端页面输入密码后，仅在当前浏览器会话中解锁该后端配置。

## 导航结构

当前界面分为六个功能域。

### 总览

**控制台**集中展示今日请求、网关代理流量、302 命中率、平均延迟、活跃播放、Emby 上游健康，以及请求/流量、状态构成、分时请求和 Source 并发图表。

### 观测中心

| 页面 | 用途 |
|---|---|
| 实时看板 | 当前播放会话、并发趋势、按 Source 并发和会话释放 |
| 流量分析 | 请求日志、状态/延迟趋势和 302 路由链路 |
| 媒体与用户 | 媒体交付方式、逻辑播放和用户使用统计 |
| 访问来源 | IP 地域、运营商、网络类型和 Top 来源 |
| 日志与事件 | 安全拦截事件和控制台原始日志 |

旧的 `/observability`、`/playback-sessions` 和 `/security-events` 地址会重定向到对应新页面。

### 流量与路由

- **Emby 源**：监听端口、上游 Emby、API Key 和路由规则。
- **路径映射**：维护真实媒体路径到后端 object key 的映射集。
- **资源池与后端**：配置存储后端和一主一备资源池。

### 存储与分发

- **对象浏览**：浏览支持目录枚举的存储，并可把目录带入 STRM 新建流程。
- **STRM 任务**：配置任务并查看最近运行和事件详情。

### 安全

- **安全规则**：真实 IP、接口防护、登录失败防护、并发限制和访问规则。
- **安全告警**：按用户、IP、规则、Source 或决策类型检测异常并发送通知。

### 系统

- **网关配置**：管理端、观察员密码、观测保留、IP 查询、GDrive Worker 和数据库维护。
- **通知中心**：配置和测试企业微信、钉钉、Telegram、Bark、Server酱等渠道。
- **缓存管理**：查看和清理网关缓存。
- **授权管理**：激活、续期、能力列表和版本检查。
- **使用说明**：当前配置拓扑和依赖健康检查。

## 配置保存与热更新

多数配置保存后立即热更新，包括后端、资源池、路由、路径映射、安全和 Source 监听器。保存成功不等于业务链路已验证；仍需发起一次真实请求并在观测中心确认结果。

## 高风险操作

以下操作会改变运行状态或删除数据，仅管理员可用：

- 清理或清空访问日志分区
- 清理缓存
- 释放播放会话
- 修改或删除凭据
- 重置 STRM 状态、删除失效文件
- 保存安全规则和并发限制

执行前先确认作用范围和可恢复方式。
