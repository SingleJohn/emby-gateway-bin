# 安全功能

「安全规则」页面包含安全引擎总开关、接口防护、真实 IP、登录失败防护、并发播放限制和自定义访问规则。

## 总开关

关闭安全引擎后，下列防护和访问规则均不生效。修改开关或规则后需要保存配置。

## 接口防护

- **禁用下载接口**：拦截 Direct File 下载路径。
- **禁用同步/离线接口**：拦截 `/Sync` 等离线与同步相关请求。

这些开关影响客户端功能。启用前确认实际使用的 Emby 客户端不会依赖相应接口。

## 真实 IP 识别

只有来自可信代理的请求，才应读取 `X-Forwarded-For` 或 `CF-Connecting-IP`：

1. 设置真实 IP Header。
2. 把反向代理出口地址加入可信代理 CIDR。
3. 除非网关只处于完全受控网络，否则不要启用“信任所有代理”。

真实 IP 会影响安全规则、登录失败防护、并发会话、日志和 IP 统计。配置错误可能让所有用户看起来来自同一个代理 IP，也可能允许客户端伪造来源。

## 登录失败防护

该功能统计指定登录路径上的失败响应，并按 IP 临时封禁：

| 配置 | 说明 |
|---|---|
| 最大失败次数 | 窗口内达到多少次后封禁 |
| 作用范围 | 按 IP 或 Source + IP 统计 |
| 统计窗口 | 失败计数的时间范围 |
| 封禁时长 | 命中后的临时拒绝时间 |
| 生效 Source | 留空表示全部 Source |
| 登录接口路径 | 需要观察的 Emby 登录路径 |
| 失败状态码 | 哪些响应计为登录失败 |

反向代理部署必须先配置正确的真实 IP，否则一个用户失败可能连带封禁共享同一代理地址的其他用户。

## 并发播放限制

并发能力分为两个独立开关：

- **统计播放会话**：维护活跃会话并在控制台和实时看板展示，不拦截播放。
- **强制并发限制**：超过限额时拒绝新播放。

可配置会话空闲超时、生效 Source、每用户默认限额、按 User ID 的独立限额、拒绝状态码和提示文案。`0` 表示不限。

会话依赖 Emby 用户识别。建议先开启“仅统计”观察一段时间，确认用户和会话口径后再启用强制限制。

管理员可在「观测中心 → 实时看板」释放某个用户或全部会话。释放会改变运行状态，不是只读排障动作。

## 自定义访问规则

规则支持以下条件：

- IP/CIDR
- User-Agent 包含或正则
- 路径前缀或正则
- HTTP 方法

动作包括允许、拒绝和速率限制。规则按页面顺序执行，第一条命中后停止。

建议顺序：

1. 最具体的允许规则。
2. 特定路径或客户端拒绝规则。
3. 速率限制规则。
4. 必要时设置兜底规则。

## 安全事件与告警

命中 `deny` 或 `rate_limit` 会写入独立的 `security_events`。在「观测中心 → 日志与事件 → 安全拦截」查看明细，在「安全 → 安全告警」配置频率、身份漂移、失败率或拦截事件告警。

详见 [安全告警](/guide/security-alerts) 和 [可观测性](/ops/observability)。

## 上线检查

- 管理端未裸露公网或已有额外访问控制。
- 管理员和观察员使用不同强密码。
- 可信代理范围最小化。
- 登录路径和失败状态码与实际 Emby 版本一致。
- 并发限制先经过“仅统计”验证。
- 新规则先在低风险 Source 验证，避免全量误拦截。
