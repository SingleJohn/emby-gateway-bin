# 123 转码

123 网盘提供官方的云端视频转码：把视频导入账号的「转码空间」，由 123 转成 HLS（m3u8）多档清晰度。网关负责决定哪些视频值得转、何时转，并在播放时选择返回原片还是 HLS。

适合这些情况：

- 原片码率高，部分客户端或网络播放卡顿，希望提供 1080P、720P 等较低档位；
- 只想给常看的视频转码，控制转码费用和空间占用。

::: warning 费用与空间
转码空间独立于网盘本身，转码可能产生 123 的真实费用。网关不会自动删除远端文件；费用以你与 123 的协议和官方返回为准。
:::

## 谁能看到

123 转码页只对**管理员**（用管理密码登录）开放，只读账号的侧栏里不显示这一项，直接访问也会被拦下。存储后端详情里的转码配置区，也只有管理员能看到「转码管理」「手动转码测试」入口。

## 配置在哪里改

转码配置属于某个 123 后端，在 <span class="ui-path">接入与路由 › 存储后端</span> 里打开该 123 后端，找到「视频转码（按需导入独立空间）」这一节。在 123 转码页顶部点「转码配置」也会直接跳过去。

配置区顶部的「当前策略」一行汇总了模式、触发、目标、容量和分发，改完先看这一行是否符合预期，再保存。手动测试使用**已保存**的配置。

### 工作模式

| 模式 | 作用 |
| --- | --- |
| 关闭 | 不调度，也不分发 HLS；仍可浏览转码空间和手动测试。 |
| 仅观察 | 记录播放热度，不新增导入或转码任务。适合先观察一段时间，看哪些视频热门。 |
| 仅复用 | 只使用已有的转码结果，不主动提交新任务。 |
| 自动转码 | 按触发策略自动导入和转码，并在播放时分发 HLS。 |

### 触发条件

- **自动转码触发策略**：
  - 「热门触发」（默认）：在「统计窗口（天）」内「有效播放次数」达到阈值才进入候选；
  - 「首播触发」：视频第一次发放播放地址后就在后台预热。当前这次播放不等待转码，之后的新会话才用上 HLS；冷门视频也会产生转码费用。
- **统计口径**：「确认播放」按播放上报的非暂停观看时长累计，配合「最小有效观看时间（秒）」使用；「去重播放请求」是按请求去重的近似口径。

### 文件范围

- 「参与转码的目录」「不参与转码的目录」：相对 123 后端根目录填写，例如 `电影` 或 `电影/动作`，不是 Emby 里的磁盘路径。留空表示全部；排除优先于包含。
- 最小 / 最大文件大小、最小 / 最大视频时长：0 表示不限制。时长在导入后由官方探测判断，不符合条件的文件会保留在转码空间里，不会自动删除。

### 转码目标

- **分辨率策略**：
  - 「固定档位」：在「目标分辨率」里多选 480P、720P、1080P、2160P（4K）等，再用「目标模式」决定转全部合法档位、只转最高档，还是按顺序只转第一个合法档位；
  - 「跟随原片」：转成官方支持的、不高于原片的最高档位。
- 实际能转哪些档位以 123 对该文件返回的能力为准。修改策略不会自动重转历史任务，需要在 123 转码页的「资源」Tab 里对任务执行「应用当前规格」。

### 容量保护

打开「启用本地容量保护」后，网关按「原文件大小 × 空间估算倍数」估算占用，超过「转码空间容量上限（GiB）」减去「保留容量比例（%）」时，不再提交新任务。同一个 123 账号下多个后端都设置了上限时，取更严格的值。

不开启时网关不做容量拦截，123 仍可能返回配额或计费错误。关闭容量保护不会删除已有的转码文件。

### 客户端分发

| 分发模式 | 行为 |
| --- | --- |
| 仅新会话 | 播放开始时就决定用原片还是 HLS；起播时没有 HLS 就整场用原片。 |
| 允许中途切换 | 起播可以先走原片，之后经过网关的请求命中已就绪的 HLS 时切过去。只对能识别 PlaySessionId 的新播放生效，切到 HLS 后不会再切回原片。 |
| 仅原片 | 始终只返回原片。转码和人工测试照常进行，适合先验证效果。 |

「高级运行参数」里还有账号最大在途任务、状态轮询间隔、异常重查间隔、连续失败暂停次数、转码链接缓存时长，一般保持默认即可。

## 123 转码页

页面顶部先选择一个已启用的 123 后端，旁边的标签显示当前模式和是否有需要处理的事项。右侧有「浏览文件」「手动测试」「转码配置」三个按钮。

### 概览

当前模式、运行状态、待处理和在途任务数、容量保护状态，以及「需要处理」「最近动态」「转码空间容量」。点击需要处理的条目会跳到「任务」Tab 并按状态筛选。

### 文件

在「转码空间（账号级）」和「云盘源视频（后端根目录）」之间切换浏览。转码空间是整个 123 账号共享的。

- 对文件可以发起「手动转码测试」、「加入生产候选」或「删除」。
- 删除转码空间里的文件会禁止相同内容被自动重新导入，而且删除的是导入的原文件，不是只删某个清晰度，操作前会有影响确认。
- 打开文件详情可以看到官方能力、官方历史记录、结果与产物，并能在「浏览器试播」里直接播放转码结果。

### 任务

「测试与操作队列」列出手动测试和自动任务。每个任务的详情里有阶段时间线、分层验证、本次参数快照，以及最近 100 次官方 API 调用（保留 trace ID，不含凭据和完整签名链接），排查失败时最有用。

### 资源

「生产任务与资源」和「热门候选」：哪些视频已经转好、哪些在排队、哪些因为热度进入了候选。

### 诊断

HLS、原片、换流地址的发放统计，统计写入丢弃情况，生命周期事件，以及容量的计算口径说明。

## 手动测试

点顶部「手动测试」进入测试入口，从云盘或转码空间里选一个文件，确认目标档位后创建测试。测试与生产隔离，不会开启自动模式，但会真实调用 123 转码，可能产生费用。点「退出测试」回到正常视图。

## 推荐的上线步骤

1. 先用「仅观察」运行几天，在「资源」Tab 的「热门候选」里确认热度统计符合预期。
2. 挑一两个文件做手动测试，在文件详情里试播，确认画质和兼容性。
3. 切到「自动转码」，分发模式先用「仅新会话」，并开启容量保护。
4. 稳定后再按需要改用「允许中途切换」。
