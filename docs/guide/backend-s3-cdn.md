# S3 与阿里云 CDN

S3 对象存储后端给对象生成预签名地址，阿里云 CDN 后端给 CDN 地址加上鉴权参数，两者都通过 `302` 让播放器直接下载，视频流量不经过网关。

媒体放在 AWS S3、MinIO、Cloudflare R2、阿里云 OSS 等对象存储里，或者已经有一个阿里云 CDN 加速域名时，看这一页。新建后端的通用流程见 [后端总览](/guide/backend-configuration)。

## S3 对象存储

<span class="ui-path">接入与路由 › 存储后端</span>，在向导里选「S3 对象存储」。

### 字段

| 界面 | 配置字段 | 默认值 | 说明 |
|---|---|---|---|
| 「Endpoint」 | `s3.endpoint` | 空 | 存储服务地址，带协议，例如 `https://oss-cn-shanghai.aliyuncs.com`。留空时使用 AWS 官方地址 |
| 「Region」 | `s3.region` | 新建时 `us-east-1`；留空也按 `us-east-1` | 区域。R2 填 `auto` |
| 「Bucket」 | `s3.bucket` | — | 必填 |
| 「Access Key」 | `s3.access_key` | — | 必填 |
| 「Secret Key」 | `s3.secret_key` | — | 必填 |
| 「签名有效期 (分)」 | `s3.sign_expiry_minutes` | `60` | 预签名地址的有效时长，最小 1 |
| 「Path Style」 | `s3.force_path_style` | 关 | 开启后地址形如 `https://endpoint/bucket/key`，关闭时是 `https://bucket.endpoint/key` |
| 「Key Prefix」 | `s3.key_prefix` | 空 | 桶内统一的前缀，会自动加在存储路径前面，首尾的 `/` 会被去掉 |

Bucket、Access Key、Secret Key 任一为空时，这个后端无法初始化，资源池会跳过它。

### 生成的地址

网关把路径映射得到的存储路径（前面加上「Key Prefix」）当作对象 Key，在本地计算预签名地址后返回 `302`。签名在网关本地完成，不会访问存储，所以：

- 对象不存在时网关也会签名成功，播放器拿到地址后才会收到 404；
- 桶不可用时同样不会触发资源池切换到备用后端，原因见 [什么时候切到备用](/guide/routing-and-pool#什么时候切到备用)。

保存后点「连接测试」，网关会用已保存的配置访问一次 Bucket，按钮显示「连接成功」或「连接失败」。测试只验证凭据和桶，不验证某个文件是否存在；要核对路径，用 <span class="ui-path">媒体库工具 › 对象浏览</span> 打开这个后端看目录。

::: tip 签名有效期设多长
播放器拖动进度时可能继续使用拿到的同一个地址，签名过期后这些请求会失败。建议有效期不短于库里最长的影片时长，例如 180 分钟。
:::

### MinIO 等兼容存储的注意点

- **Endpoint 要让播放器也能访问。** 预签名地址里的域名就是「Endpoint」，播放器会直接连这个地址。只填内网地址（如 `http://192.168.1.5:9000`）时，外网的播放器播不了。
- **地址不能被改写。** 签名包含了域名，在 MinIO 前面加反向代理时，「Endpoint」要填反向代理对外的地址，且反向代理要原样转发 `Host`。不要在网关返回地址后再替换域名。
- **MinIO 一般要开「Path Style」。** 没有给每个桶配置子域名时，关闭 Path Style 会生成 `bucket.域名` 形式的地址，解析不到。阿里云 OSS 等云厂商的存储一般保持关闭。
- **Region 与服务端一致。** MinIO 默认区域是 `us-east-1`；在 MinIO 里改过区域的，这里要填相同的值，否则签名不匹配。
- **时间要准。** 预签名用网关所在机器的时间计算，时间偏差较大时，存储会认为地址已过期或尚未生效。

## 阿里云 CDN

在向导里选「阿里云 CDN」。这个后端只负责签发 CDN 地址：网关把存储路径接在「Base URL」后面，再按鉴权规则加上参数。CDN 回源到哪里，在阿里云 CDN 控制台里配置。

### 基本配置

| 界面 | 配置字段 | 默认值 | 说明 |
|---|---|---|---|
| 「Base URL」 | `aliyun_cdn.base_url` | — | CDN 加速域名，例如 `https://cdn.example.com`。必填 |
| 「路径转义」 | `aliyun_cdn.path_escape` | 新建时开 | 开启后，路径里的中文、空格等字符先做 URL 编码再签名和拼接。一般保持开启 |

### 鉴权设置

| 界面 | 配置字段 | 默认值 | 说明 |
|---|---|---|---|
| 「鉴权模式」 | `aliyun_cdn.auth.mode` | `aliyun` | 「阿里云 Type A」或「123 回源鉴权」 |
| 「启用鉴权」 | `aliyun_cdn.auth.enabled` | 新建时开 | 关闭后只拼接地址，不加鉴权参数 |
| 「鉴权密钥 (Secret)」 | `aliyun_cdn.auth.secret` | — | 与控制台里设置的鉴权密钥一致。启用鉴权时必填 |
| 「链接有效期 (秒)」 | `aliyun_cdn.auth.expires_seconds` | `1800` | 最小 60，含义见下文 |
| 「参数名」 | `aliyun_cdn.auth.param_name` | `auth_key` | 鉴权参数的名字，与控制台一致。「123 回源鉴权」模式下固定为 `auth_key`，不显示此项 |

::: tip 密钥不回显
已保存的「鉴权密钥 (Secret)」不会显示在页面上，输入框提示「已设置，留空保留原密钥」。要更换时填新密钥并保存；留空保存会保留原来的密钥。
:::

**「阿里云 Type A」模式**按阿里云 CDN 的 A 类鉴权生成 `auth_key`，签名里的时间是签发时间。链接实际多久失效，由阿里云控制台里配置的鉴权有效时长决定；「链接有效期 (秒)」请填成和控制台相同的值，网关用它显示和记录到期时间。签名里的用户字段会填当前播放的 Emby 用户 ID，取不到时用 `0`，方便在 CDN 日志里区分用户。

**「123 回源鉴权」模式**用于 CDN 回源到 123 网盘直链空间的场景，按 123 直链的 URL 鉴权规则签名：

- 多出一个「123 账号 UID」（`aliyun_cdn.auth.uid`），填 123 账号的数字 UID。启用鉴权时必填；
- 「鉴权密钥 (Secret)」填 123 网页端直链的 URL 鉴权密钥；
- 签名里的时间是到期时间，「链接有效期 (秒)」直接决定链接多久失效；
- 「Base URL」只能是 `http(s)://域名`，不能带路径、查询参数或用户信息；
- 不使用「路径转义」，存储路径按原样（解码后的完整文件路径）签名，不需要加 UID 前缀；
- CDN 回源时要把 `auth_key` 参数一起带给 123，否则 123 会拒绝回源请求。

123 网盘本身的配置见 [123 网盘](/guide/backend-123)。

### 单请求限速

阿里云 CDN 的「单请求限速」可以通过 URL 参数限制单个请求的下载速度。网关只负责把数值写进地址：

| 界面 | 配置字段 | 默认值 | 说明 |
|---|---|---|---|
| 「启用限速参数」 | `aliyun_cdn.rate_limit.enabled` | 关 | |
| 「参数名」 | `aliyun_cdn.rate_limit.param_name` | `rate` | 与控制台里自定义的参数名一致，不能是 `auth_key` |
| 「限速值」 | `aliyun_cdn.rate_limit.value` | — | 填数字，单位（KB/MB）以控制台为准。为 0 时不添加参数 |

需要先在阿里云 CDN 控制台开启「单请求限速」，参数名和单位都以控制台为准。

### 签名测试

点「生成签名测试」打开「CDN 签名测试」：

1. 在「Object Key」里填一个存储路径，例如 `movies/avatar.mkv`；
2. 「阿里云 Type A」模式下可以在「UID (Opt)」里填一个用户 ID，留空用配置值；
3. 点「生成」，下面显示完整的签名地址和到期时间。

把生成的地址复制到浏览器或下载工具里访问，能下载就说明 CDN、回源和鉴权都配对了。测试使用**已保存**的配置，改完先保存再测。

## 两者组合使用

常见做法：媒体存在 OSS 或其他 S3 兼容存储里，前面挂阿里云 CDN 加速，播放走 CDN，扫描目录走 S3。

1. **阿里云控制台**：添加加速域名，源站指向存储桶；源站是私有桶时开启私有 Bucket 回源；开启 A 类 URL 鉴权，记下密钥和有效时长。
2. **新建「阿里云 CDN」后端**：「Base URL」填加速域名，「鉴权模式」选「阿里云 Type A」，「鉴权密钥 (Secret)」和「链接有效期 (秒)」与控制台一致。保存后用「生成签名测试」验证。
3. **新建「S3 对象存储」后端**：指向同一个桶。它用于 [对象浏览](/guide/file-browser) 和 [STRM 任务](/guide/strm-guide)，因为阿里云 CDN 后端没有列目录的能力。
4. **路径对齐**：CDN 后端直接把存储路径拼在域名后面，不会加「Key Prefix」。两个后端要用同一个存储路径找到同一个文件，最简单的做法是 S3 的「Key Prefix」留空，需要的前缀写进 [路径映射](/guide/path-mapping) 的「存储中的路径前缀」。
5. **资源池**：「主用后端」选 CDN。要不要把 S3 放进「备用后端」看需求：CDN 签名在本地完成，CDN 故障不会触发切换，备用只在 CDN 后端配置有误或被停用时才会用上。
6. **路由规则**：在 [Emby 源](/guide/emby-sources#路由规则) 里让对应目录的规则指向这个资源池。

::: warning 不要把 S3 当作 CDN 的自动故障兜底
CDN 回源失败、域名欠费停用等问题，网关都检测不到，播放器拿到 CDN 地址后才会报错。需要应急时，到资源池里把主用、备用对调，或停用 CDN 后端，让播放直接走 S3。
:::

## 常见问题

**播放器跳转后返回 403。**
S3：检查 Region、Path Style 和机器时间，并确认 Endpoint 没有被反向代理改写。CDN：确认「鉴权密钥 (Secret)」「参数名」与控制台一致，并确认「路径转义」的开关和实际文件名匹配，用「生成签名测试」得到的地址直接访问对比。

**中文文件名在 CDN 上 404。**
保持「路径转义」开启。关闭时中文和空格原样拼进地址，部分客户端或 CDN 会处理出错。

**「连接测试」成功，播放却 404。**
连接测试只检查桶。到对象浏览里按路径映射的结果逐级找到文件，常见原因是多了或少了一层目录、大小写不一致，或「Key Prefix」和映射里的前缀重复了。

**MinIO 在内网能播，外网不能播。**
预签名地址里是「Endpoint」的域名。把「Endpoint」改成外网可访问的地址（通常是 MinIO 前面反向代理的公网域名）。
